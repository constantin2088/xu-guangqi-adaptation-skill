# 可填写工作表

## 第1步
明确要解决的本地问题和采用外部知识的理由，给维持现状及其他方式同等比较。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第2步
确认引入内容的原理、来源、版本和适用条件，区分译者说明、前人材料、亲测与推断。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第3步
逐项对照本地资源、环境、人员、接口与制度限制，列必须改变和不能改变的条件。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第4步
设计最小可逆试点，约定基准、观察指标、测量方式、成本上限与停止条件，先确认实施权限。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第5步
记录差异和失败，不将“不懂原理”与“环境不适配”混在一起；调整时只改可追踪的关键条件。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第6步
设置扩展门槛和知识交接，输出适配表与未决项；小试有效不自动证明大规模或长期有效。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 证据和行动校验
关键条目至少填写一个来源定位（source）或下一步核验（next_check）。不将表格通过当作论证真实。可以用 `python scripts/validate_packet.py packet.json` 检查结构，工具不访问网络、不评判观点或代替专业审查。

## 确定性辅助工具

同单位、同条件、按配对编号比较观测差异；不推断因果或大规模有效性。

输入例子见 [tool-input.json](../examples/tool-input.json)。
```sh
python scripts/check_trial.py examples/tool-input.json
```
工具只读取指定本地 JSON，不联网、不更改文件、不执行输入中的指令。填写者仍须复核事实和适用条件。
